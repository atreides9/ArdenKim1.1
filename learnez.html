Learn-EZ

질문하고 판단하는 힘을 기르는 AI-native 학습 유니버스. 온보딩, 퀘스트, 여권, 글로벌 미션까지 이어지는 모바일 학습 경험을 설계하고 구현했습니다.

01. Overview

개요

Learn-EZ는 특정 과목 하나를 학습하는 앱이 아니라, 사용자가 국가·학습 맥락·관심 분야를 선택하면 자신만의 학습 세계를 탐험하도록 설계한 모바일 프로토타입입니다. 학습 분야는 질문과 판단, 인간중심 AI, 돈과 경제, 사회와 세계, 과학, 역사, Global Agora, 미래 프로젝트처럼 교과와 삶의 주제를 함께 다룹니다.

02. Problem

학습은 콘텐츠보다 지속되는 구조가 어렵다

지식 콘텐츠는 이미 넘쳐나지만, 사용자가 꾸준히 돌아와 생각하고 판단하는 구조는 부족합니다. 많은 학습 서비스는 과목별 콘텐츠를 제공하는 데 집중하지만, 사용자가 왜 배우는지, 다음에 무엇을 해야 하는지, 배운 내용이 삶의 판단과 어떻게 연결되는지는 흐려지기 쉽습니다.

콘텐츠는 많지만 학습자가 다시 돌아오게 만드는 진행감이 약하다
교과와 삶의 주제가 분리되어 학습의 맥락이 끊긴다
정답 암기와 가치 판단, 토론형 사고가 같은 방식으로 다뤄진다
게임화가 보상에만 치우치면 학습 자체의 의미가 약해진다
03. Product Concept

교과 앱이 아니라, 학습 세계를 설계했다

Learn-EZ의 핵심 컨셉은 “세상을 배우는 가장 재밌는 방법”입니다. 국가와 학습 맥락을 기반으로 출발점을 잡고, 관심 분야를 선택하면 사용자는 세계 지도와 학습 경로를 따라 퀘스트를 완료합니다. 학습은 단일 화면의 문제 풀이가 아니라, 탐험과 기록, 협동 미션으로 이어지는 경험이 됩니다.

Personalized Start

국가, 미성년/성인 경로, 학년 또는 커리어 맥락, 관심 분야를 받아 학습 출발점을 조정합니다.

Learning Universe

12개 분야를 코스 카탈로그로 구성해 사용자가 교과와 삶의 주제를 넘나들 수 있도록 설계했습니다.

Quest Narrative

세계 지도, 국가 탐험, 퀘스트 노드, 여권 도장을 통해 학습 진행을 시각적인 여정으로 만듭니다.

04. Experience System

온보딩에서 재방문까지 이어지는 학습 루프

Learn-EZ는 첫 선택부터 복습과 미션까지 하나의 루프로 연결됩니다. 사용자는 관심 분야를 고르고, 세계 지도에서 국가를 선택하고, 퀘스트를 풀고, 피드백을 받은 뒤 다음 미션을 해금합니다. 여권, 스트릭, 글로벌 미션, 월간 배지는 이 루프를 다시 시작하게 만드는 장치입니다.

1Onboarding국가, 학습자 유형, 학년/커리어, 관심 분야를 선택합니다.
2Course Universe관심사 기반으로 다양한 학습 분야를 추천하고 전환합니다.
3Quest & Quiz정답형/관점형 퀴즈를 통해 지식과 판단을 함께 다룹니다.
4Mission & PassportXP, 여권, 글로벌 미션, 배지로 학습의 지속 동기를 만듭니다.
05. Key Decisions

핵심 결정 3가지

Decision 01

과목보다 역량 중심으로 분야를 구성

단순 과목 앱처럼 보이지 않도록 질문과 판단, 인간중심 AI, 돈과 경제, 사회와 세계, 미래 프로젝트처럼 “세상을 읽는 힘”을 기준으로 카테고리를 설계했습니다.

Decision 02

정답형과 관점형 퀴즈를 분리

물리·역사처럼 근거로 확인할 수 있는 문제는 정답형으로, 커뮤니케이션·윤리·사회 이슈처럼 맥락이 중요한 문제는 관점형으로 설계해 학습 목표를 다르게 다뤘습니다.

Decision 03

보상은 학습 접근권이 아니라 지속 동기에만 사용

스파크는 힌트와 아바타 꾸미기에 사용하도록 설계하고, 기본 학습과 복습은 결제로 막지 않았습니다. 학습 기회보다 동기와 표현을 보상하는 구조를 우선했습니다.

06. AI-native Build Process

AI와 함께 제품 구조를 빠르게 구현했다

Learn-EZ는 AI를 단순한 화면 생성기가 아니라, 제품 구조를 빠르게 구체화하고 구현하는 협업 파트너로 활용한 프로젝트입니다. 컨셉, IA, UI 상태, 콘텐츠 구조, 인터랙션을 브라우저에서 직접 확인하며 반복했습니다.

1

Product framing — “학습을 세계 탐험으로 바꾸는 앱”이라는 중심 메타포와 주요 루프 정의

2

IA & screen flow — 온보딩, 코스, 지도, 퀴즈, 미션, 여권, 프로필, 상점까지 화면 상태 설계

3

Prototype build — HTML/CSS/JS 단일 앱으로 모바일 우선 인터랙션 구현

4

Iteration — 브라우저에서 직접 테스트하며 퀘스트 경로, 힌트, 결과, 보상 흐름을 조정

08. Learnings

AI 시대의 학습 제품은 콘텐츠보다 루프가 중요하다

✓ Product

  • 범용 학습 제품은 자유도보다 반복 가능한 구조가 먼저 필요하다
  • AI 기능보다 “왜 다시 돌아오는가”를 설명하는 루프가 중요하다

✓ UX/UI

  • 복잡한 시스템도 하나의 메타포로 묶으면 탐색 부담이 줄어든다
  • 게임화는 보상보다 의미 있는 진행감과 기록으로 설계해야 한다

✓ AI-native Build

  • AI 협업은 구현 속도를 높이지만, 제품 판단과 윤리 원칙은 사람이 잡아야 한다
  • 브라우저에서 바로 눌러보는 반복이 화면 설계의 밀도를 높였다
